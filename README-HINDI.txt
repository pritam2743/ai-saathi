AI SAATHI WEBSITE — SETUP (HINDI)
=================================
Included: Home, Tools directory with search/filter, Categories, Guides, About, Contact, Privacy Policy, Disclaimer, responsive CSS, JS, favicon, robots.txt, sitemap.xml, ads.txt.

LOCAL TEST:
1. ZIP extract karo.
2. Folder ke andar index.html double-click karo.
3. Mobile menu, search, categories aur links test karo.

FREE PUBLISH VIA GITHUB PAGES:
1. github.com par free account/login.
2. New public repository banao, e.g. ai-saathi.
3. ZIP extract karo; extracted folder ke ANDAR ki files repository root mein upload karo. index.html root mein hona chahiye.
4. Repository Settings → Pages.
5. Build and deployment: Deploy from a branch; branch main; folder /(root); Save.
6. Settings → Pages mein live URL milega. Publish hone mein kuch minute lag sakte hain.

PUBLISH SE PEHLE:
- contact.html aur privacy.html mein YOUR_EMAIL@example.com ko apne actual email se replace karo.
- sitemap.xml mein YOUR-PUBLISHED-URL ko actual published URL se replace karo; ya URL set karne tak sitemap submit mat karo.
- Privacy policy ko actual cookies, analytics aur ad setup ke hisaab se edit karo.
- Tool features, URLs aur current pricing verify karo.
- Google Fonts online load hota hai; other main CSS/JS files local hain.

ADS:
- Ad boxes filhaal placeholders hain, earning nahi karte.
- AdSense approval ke baad official account se site connect karo aur exact instructions follow karo.
- AdSense Vignette/Auto ads account settings se enable kiye ja sakte hain if available and appropriate; har page change par ad guaranteed nahi hai.
- ads.txt mein sirf wahi exact publisher line add karo jo AdSense account provide kare.
- Khud ads click na karo, fake traffic na lao, visitors se ad click karne ko na kaho.

This is a static website. It does not include backend, login, database, payments or a contact-form server. Contact button opens an email app.
